# GouNow Platform - Frontend

The client-facing web application and static assets for El Gouna Lifestyle Platform, deployed to GitHub Pages.

## Directory Structure
- `index.html`: Main landing page (luxury stays, experiences, El Gouna concierge).
- `stays/`: Vacation rentals, lagoon chalets, and waterfront villas catalog and details.
- `experiences/`: Curated adventures (private yachts, desert buggy, kitesurfing).
- `admin/`: Admin portal, login screens, and dashboard views.
- `checkout/`: Booking confirmation and checkout views.
- `assets/`: Branding logos, sand textures, and icon assets.
- `build/`: Production compiled Tailwind CSS and JavaScript bundles.
- `sitemap.xml`: SEO sitemap for search engine discovery.
- `robots.txt`: Search crawler directives.
